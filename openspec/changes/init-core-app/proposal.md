# Proposal: Core Flashcard Application

## Why
We need to build a specialized chemistry flashcard system for Shanghai high school students to improve their memorization of knowledge points through spaced repetition.

## What Changes
- Set up the foundational react architecture.
- Create the core flashcard UI capable of showing chemistry questions and answers.
- Implement the baseline Spaced Repetition (Anki SM-2 style) logic.
- Integrate local IndexedDB for secure, offline-first data storage.

## Capabilities

### New Capabilities
- `core-flashcard`: The ability to review flashcards, rate their difficulty, and schedule the next review.

## Impact
- Scaffolds the entire application.
- Establishes the foundational aesthetic and technical patterns.
